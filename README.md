# 基于 SpringBoot + Vue 的食堂采购系统 (Canteen Procurement System)

采购申请 · 审批流转 · 入库管理 · 出库管理 · 库存盘点 · 供应商管理 · 采购组合 · 单据导出 · 多角色协同

本项目是一套面向高校、企业园区、医院及机关单位食堂的采购与库存一体化管理系统，采用前后端分离架构，覆盖管理员、食堂商家与库房管理员三类角色。系统围绕"物资采购、申请审批、入库管理、出库管理、库存盘点、供应商管理、采购组合、单据导出"等核心业务设计，支持食堂商家在线提交食材申请、管理员审批与生成采购单、库房管理员验收入库、按需出库至各食堂档口，实现从采购申请、审批、采购、入库、出库到库存盘点的全流程数字化管理，适用于高校食堂、企业员工食堂、医院营养食堂、机关单位食堂及连锁餐饮中央厨房的日常运营。

## 核心特性

- **多角色权限管理**：区分管理员、食堂商家与库房管理员三类角色，实现不同权限隔离与功能访问控制。
- **采购申请与审批**：食堂商家在线提交食材采购申请，管理员审核申请并生成采购单，支持审批流程与状态追踪。
- **供应商管理**：维护供应商档案，包括公司名称、联系人、资质证件、供货品类、合作状态与评级，支持供应商准入审核。
- **采购组合管理**：支持将常用食材打包为采购组合（如"早餐套餐包""火锅食材包"），一键生成采购单，提升采购效率。
- **入库管理**：库房管理员根据采购单验收货物，记录入库数量、批次、保质期与存放位置，支持采购单入库与库房入库操作。
- **出库管理**：根据食堂商家的领用需求进行出库，记录出库数量、领用档口、用途与经办人，支持出库单下载。
- **库存盘点**：定期执行物资盘点，比对系统库存与实际库存，生成盘盈盘亏差异报告，支持库存调整。
- **出入库明细**：完整记录每件物资的出入库流水，包括时间、数量、经办人、关联单据，实现库存全流程可追溯。
- **单据导出**：支持入库单与出库单导出为 Excel/PDF 格式，便于财务对账与审计存档。
- **公告信息**：管理员发布采购通知、库存预警、食品安全提示等公告，触达食堂商家与库房管理员。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、采购审批、供应商管理、库存监控与数据统计：

### 用户与角色管理

- **用户管理**：管理注册用户信息，包括食堂商家账号、库房管理员账号，支持账号启用/禁用与密码重置。
- **角色管理**：配置系统角色与权限，如管理员、食堂商家、库房管理员，支持自定义角色与权限分配。

### 采购与审批管理

- **申请审批**：审核食堂商家提交的物资采购申请，查看申请明细、数量、期望到货时间，支持通过/驳回操作与审批意见填写。
- **物资采购**：根据审批通过的申请生成采购单，选择供应商，确认采购数量与单价，生成正式采购订单。
- **采购组合**：管理常用食材采购组合，如"早餐套餐包""火锅食材包""面点原料包"，支持组合内物品增删与一键生成采购单。

### 供应商与基础数据管理

- **供应商管理**：维护供应商档案，包括公司名称、联系人、联系电话、地址、营业执照、供货品类、合作状态与评级，支持供应商准入审核与禁用。
- **物品类型**：管理物资分类体系，如蔬菜、肉类、水产、粮油、调味品、冻品、餐具耗材等，支持多级分类。
- **计星单位**：管理物资计量单位，如千克、克、斤、两、箱、袋、瓶、个等，支持单位换算配置。

### 库房与出入库管理

- **库房信息**：管理仓库/库区信息，包括仓库名称、位置、温度类型（常温/冷藏/冷冻）、容量、负责人。
- **库房物品**：查看当前库存物品清单，包括物品名称、规格、库存数量、存放位置、保质期、预警状态。
- **入库管理**：查看待入库采购单，库房管理员验收入库后更新入库状态，记录入库数量、批次与存放位置。
- **出库管理**：处理食堂商家的领用出库请求，确认出库数量与领用档口，更新库存。
- **出入库明细**：查看所有物资的出入库流水记录，包括时间、物品、数量、经办人、关联单据，支持按时间、物品、操作类型筛选。
- **物资盘点**：执行库存盘点，录入实际库存数量，系统自动比对生成盘盈盘亏差异报告，支持库存调整审批。

### 公告与单据管理

- **公告信息**：发布平台公告，包括采购通知、库存预警、食品安全提示、系统维护通知等，支持置顶与定时发布。
- **出库单&入库单下载**：支持导出入库单与出库单为 Excel/PDF 格式，包含单据编号、物品明细、数量、单价、金额、经办人、时间等信息，便于财务对账。

---

## 食堂商家端

食堂商家面向各食堂档口/窗口负责人，提供物资申请、申请记录查询与出库单下载功能：

### 账户与信息管理

- **商家信息变更**：维护食堂档口信息，包括档口名称、负责人、联系方式、经营品类、所属食堂区域。

### 采购申请

- **物品申请**：在线提交物资采购申请，选择物品类型、填写数量、期望到货时间与备注说明，支持批量添加物品。
- **申请记录**：查看个人提交的采购申请记录，包括申请状态（待审批/已通过/已驳回/已采购/已入库）、审批意见与预计到货时间。

### 出库管理

- **出库单下载**：物资入库后可申请领用出库，下载出库单作为领用凭证，支持导出 Excel/PDF 格式。

---

## 库房管理员端

库房管理员负责仓库日常运营、采购单验收与入库操作：

### 库房管理

- **库房信息**：查看所负责仓库的基本信息，包括仓库名称、位置、温度类型、容量与当前库存概览。

### 入库操作

- **采购单入库**：查看待入库的采购单，核对到货物品与数量，验收合格后确认入库，记录实际入库数量、批次与存放位置。
- **库房入库**：处理非采购类入库（如退货入库、调拨入库、盘盈入库），录入入库物品信息与数量。

### 公告查看

- **公告查看**：浏览管理员发布的公告信息，了解采购通知、库存预警与工作安排。
